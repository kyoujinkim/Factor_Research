# Factor_Research

글로벌 주식 팩터의 **포트폴리오 구성 → 지수 백테스트 → 기대수익률·베타 추정 → 업종·종목별 집계**를 연결하는 Python 퀀트 리서치 프로젝트입니다.


## 연구 결과

2024년 자산평가모형 보고서의 시점 외 평가 기간은 **2019-01-04-2024-03-29**입니다. 월말 마지막 금요일 리밸런싱, 기대수익률 상위 20% 중 최대 200종목, 종목당 최대 5% 비중을 사용했습니다. 시가총액 하위 5%, 기대수익률 상위 10개 이상치 등을 제외했으며 **거래비용은 반영하지 않았습니다**.

| 시장·보고서 선택 모형 | 모형 누적수익률 | 시가총액 가중 BM | 모형 MDD | BM MDD |
|---|---:|---:|---:|---:|
| 미국·CH4F | 187.5% | 116.8% | −35.5% | −34.5% |
| 유럽·CAPM | 52.9% | 65.1% | −26.7% | −31.7% |
| 한국·SR | 96.0% | 50.7% | −45.1% | −32.8% |
| 일본·SR | 120.1% | 83.3% | −31.7% | −28.4% |

수익률 개선이 위험 조정 성과 개선과 항상 일치하지는 않았습니다. 미국의 Sharpe는 모형 0.84, BM 0.92였고, 유럽은 시가총액 가중 BM보다 누적수익률이 낮았습니다. 한국·일본은 더 높은 수익률과 함께 더 큰 최대낙폭을 기록했습니다.

보고서의 선택 설정은 미국 CH4F(평균 3개월·베타 12개월), 유럽 CAPM(6·12), 한국 SR(3·60), 일본 SR(6·60)입니다. 현재 config의 한국·일본 모형과 일부 기간 설정은 보고서와 다르며, 코드의 중국 확장은 위 표의 검증 대상이 아닙니다. 따라서 위 성과를 현재 기본 설정의 재현 결과로 해석하지 않습니다.

## 주요 기능

- 가치·규모·모멘텀·수익성·투자·반전 팩터와 시가총액 벤치마크 구성
- 리밸런싱 비중을 이용한 팩터 지수 계산과 저장 상태에 따른 증분 갱신
- 시장별 회귀모형을 이용한 기대수익률·팩터 노출도 추정
- 국가·규모·업종·종목 단위 CSV와 연구 노트북 생성
- Refinitiv/LSEG·Datastream 원천 데이터의 조회·저장·가공 모듈

## 설치·데이터 준비

저장소 루트에서 별도 가상환경을 사용합니다.

```bash
python -m pip install -r requirements.txt
```

`config.py`의 `DB_PATH`와 `CONFIG_INI`를 로컬 환경에 맞게 설정합니다. 필요한 입력에는 종목 마스터 `equity_master.db`, 데이터 정의 `data_master.json`, `members/master_<index>.parquet`, 종목별 가격·배당·재무 파일, `rf.xlsx` 등이 있습니다. 업종 집계는 `output/industry_map_gics.csv`도 사용합니다. 코드를 내려받는 것과 원천 데이터가 준비되는 것은 별개입니다.

갱신용 비공개 INI는 `[main] api_key`, `[dsws] id`, `[dsws] pw`를 사용합니다. 실제 값은 저장소에 넣지 않습니다. 외부 조회에는 해당 금융데이터 서비스의 접근 권한과 세션이 필요합니다.

## 실행

```bash
# 데이터 갱신: 외부 조회 및 로컬 파일 변경
python updateData.py

# 미국 전체 팩터의 최초 비중·지수 계산, 기대수익률 스냅샷
python main_v2.py --c us --recalc-weight --rebuild-index --skip-er-history

# 준비된 기존 파일을 이용한 갱신
python main_v2.py --c korea --skip-er-history
```

| 옵션 | 의미 |
|---|---|
| `--c` | 시장 선택. `us europe japan korea china` |
| `--f` | 비중 재계산 대상 팩터 선택 |
| `--d` | 기대수익률 스냅샷 기준일 |
| `--recalc-weight` | 기존 비중 없이 처음부터 계산 |
| `--rebuild-index` | 팩터 지수 전체 재계산 |
| `--skip-er-history` | 전체 기대수익률 이력 계산 생략 |

최초 실행에는 기존 비중 파일이 없으므로 전체 팩터부터 준비하는 것이 좋습니다. `--f`로 일부만 선택해도 이후 집계가 다른 팩터의 기존 파일을 참조할 수 있습니다. 모듈 로딩 시 DB를 읽는 경로도 있어 도움말 실행 전 데이터 설정이 필요할 수 있습니다.

## 산출물·활용

`weight/<country>/factor_weight/`에 비중, `output/<country>/bm/`에 지수, `output/<country>/Expected_Return/`에 기대수익률·베타, `output/0.export/<country>/`에 집계 CSV를 저장합니다.

팩터 노출을 이용한 시장·업종 비교와 기대수익률 분해에 사용할 수 있습니다. 추정치는 모형·원천 데이터·가용 시점·통화·리밸런싱에 의존합니다. 과거 구성종목, 회계정보 공시 시차, 배당, 거래비용을 통제한 시간순 검증이 필요합니다.
